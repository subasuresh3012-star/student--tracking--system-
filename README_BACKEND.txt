# Student Tracking System - Backend

Backend: Node.js + Express (no PHP).

## Run
1. Install Node.js LTS.
2. Open this backend folder in VS Code.
3. Run `npm install`
4. Run `npm start`

The backend runs at http://localhost:3000 and serves the frontend files from the `public` folder.
For the combined project, keep `server.js`, `package.json`, and the `public` folder together in one project root.
